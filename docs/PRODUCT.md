# PRODUCT — 用户行为

> 系统实现见 [ARCHITECTURE.md](ARCHITECTURE.md)；验证纪律见 [RELIABILITY.md](RELIABILITY.md)。

## 1. 定位

单用户本地 Web 个人助手：对话、读写文件、运行命令、管理任务、派出子助手。

| 项 | 约定 |
|---|---|
| 使用范围 | 桌面、中文、浅色主题；无登录/多用户 |
| 布局 | 左侧会话列表 + 中间对话 + 右侧子助手面板 |
| 面板 | 左栏可收起并记忆；右栏点卡打开、X 收起、再点恢复 |
| 数据 | 会话与日志保存在本机；对话上下文发送至配置的模型 API |
| 工作区 | 文件工具默认操作固定工作区；命令按授权执行 |

## 2. 会话

| 操作 | 行为 |
|---|---|
| 新建 | 先建草稿；发送首条消息才保存；标题取首条消息前 30 字，不可改名 |
| 列表 | 按更新时间倒序；标题、时间、累计输出 token；生成中显示呼吸点，每 5s 刷新 |
| 继续 | 打开历史会话，回看并续聊 |
| 删除 | 两步确认；界面不可恢复；生成中需先停止 |
| 地址 | / 为欢迎页；/session/{id} 为会话页 |
| 刷新 | 已保存会话恢复回放；草稿、未知、已删地址回首页 |
| 空状态 | 欢迎页引导新建；草稿页提示发送首条消息 |

## 3. 对话

### 3.1 输入与操作

- Enter 发送；Shift+Enter 换行；空文本不可发送。
- 同会话仅一个回复任务；重复提交拒绝；不同会话可并行。
- 主循环每turn最多40个模型步；达到上限且仍需继续时失败收口，不自动重试模型错误。
- 生成时显示停止按钮；停止在执行检查点生效，保留已生成正文。
- 消息可复制；错误可重试；重新生成始终重跑**最后一轮**。
  - 保留最后用户消息，替换该轮回复。
  - 与发送共用停止、审批和用量规则。
  - 已执行的文件/命令操作不会撤销。

### 3.2 展示结构

**用户消息 → 工作块 → 最终回复。** 纯文本轮无过程条目时不显示工作块。

| 状态 | 块头 | 默认展开 |
|---|---|---|
| 生成中 | 工作中 {耗时} | 是 |
| 成功 | 总耗时 {耗时} | 完成后收起，可展开 |
| 失败 | 已失败 {耗时} | 是 |
| 停止/中断 | 已停止；有工时则显示耗时 | 是 |

- 运行中耗时为本地秒表；结束后以服务端总耗时为准，包含审批等待。
- 格式：45s / 3m 05s / 1h 00m 00s。
- 最终回复支持 Markdown、代码高亮、复制；主动停止的部分正文标记“已停止”。

### 3.3 工作块内容

| 条目 | 展示 |
|---|---|
| 工具卡 | 工具、参数、状态、可展开输出；流中仅预览，结束后取保存输出 |
| 聚合组 | 连续 read_file/glob ≥2 为“探索”；连续 bash ≥2 为“执行” |
| 子助手卡 | 目标、状态；点开右栏查看运行/历史输出 |
| 任务板 | 待办/进行中/已完成；整板更新，≤20 项、最多 1 项进行中 |
| 审批卡 | 等待/批准/拒绝；同一审批保留一张最终状态卡 |
| 错误/压缩 | 内联错误与重试；发生压缩时提示“已压缩上下文” |

## 4. 权限

### 4.1 模式

输入卡选择模式；**随下一次发送生效**。模式与规则按项目保存至 SQLite local_setting；当前固定工作区共享，新项目默认 build。

| 模式 | 行为 |
|---|---|
| 变更前确认 build（默认） | 只读免批；写、改、删与一般命令确认 |
| 自动编辑 edit | 写/改文件免批；删除与一般命令仍确认 |
| 完全访问 yolo | 直接执行；禁止清单与文件越界仍拒绝 |

- 命中允许规则可免批；完全访问可从审批弹窗授予，持续至切换模式。
- 命令工作目录不等于系统隔离；完全访问不限制命令只能影响工作区。

- 项目标识由规范工作区路径生成；只保存 permission 的 mode/ruleset。
- 不迁移旧权限 JSON；首次使用新存储默认 build、空规则。旧文件保留但不再读取。

### 4.2 审批

1. 弹窗显示工具、原因、参数；非文字输入时，数字键按选项序号选择。
2. 可选项随请求变化：

   | 选项 | 效果 |
   |---|---|
   | 仅本次允许 | 执行当前操作 |
   | 完全访问 | 切换 yolo；子助手实时审批不提供 |
   | 总是允许 | 仅命令请求提供；保存规则并执行 |
   | 拒绝 | 不执行；可附 ≤4096 字符反馈给模型 |

3. 普通命令按首词记规则；高危根命令仅记整条精确规则。
4. 审批等待计入总耗时；服务仍在运行时，刷新可恢复未决弹窗。

## 5. 用量与边界

| 场景 | 行为 |
|---|---|
| 上下文徽标 | 最近已结束轮的输入 token / 窗口 / 百分比；结束后更新，无数据隐藏 |
| 上下文压缩 | 缩短模型历史；较旧工具输出可能被占位符替换 |
| 刷新/断线 | 后台任务继续；仅回放已保存内容，不恢复实时流 |
| 多标签页 | 发起任务的标签接收实时流；其他标签刷新回看 |
| 服务重启/崩溃 | 未收口轮显示已停止；保留已落盘内容，可重跑 |
| 修改系统提示词 | 下一轮读取新内容 |

上下文徽标读取会话回放中的用量；前端不保存未展示的实时 token 副本。

**待验证限制（源码静态发现，尚未修复）：**

- 审批弹窗无停止入口；后端审批等待也未接停止信号。
- 刷新显示运行态；服务重启不恢复审批卡片。
- 普通工具运行卡不会及时出现。

## 6. 视觉规范

| 项 | 约定 |
|---|---|
| 方向 | Fluent 产品界面原则；白色、微暖灰、石墨文字、暖金黄强调；变化6 / 动效3 / 密度4 |
| 层次 | 淡灰导航、白色工作区；会话标题、过程、正文、输入分别呈现 |
| 组件 | 统一按钮、8/12/16/20px圆角、系统字体；Markdown标题/列表/表格/代码有明确排版 |
| 交互 | 图标配文字或可访问名称；键盘焦点可见；审批焦点留在弹窗，输入反馈不触发数字快捷键 |
| 状态 | 提供空态、加载与请求失败提示；减少动态效果设置下关闭非必要动画 |
| 窄窗口 | 导航改为抽屉；子助手面板覆盖显示；不增加移动端专属功能 |

审视结论：保留路由、三栏职责、权限选项；重做欢迎页、导航、输入卡与工作卡；修复嵌套按钮及弱对比文字。

## 7. 非目标

- 内容：附件、thinking 展示、跨会话记忆、每会话模型切换。
- 会话：搜索、重命名、归档、导出。
- 界面：深色主题、多语言、移动端、工作区文件浏览器。
- 平台：登录、多用户、SSE 断点续传、长会话分页/虚拟化。

## 存储重构（2026-10-09）

用户与助手正文统一存内容部件，界面与一问多步行为不变；不迁移旧库，重建仅清会话数据库，不清工作区或权限规则。

## 存储子集重构（2026-10-10）

- 保留现有会话、工具、任务板和审批交互。
  - 耗时显示本轮总耗时，包含审批等待。
  - 审批卡片仅本次服务进程保留；重启不显示历史审批卡片或失效弹窗。
- 数据库采用 ZCode 六表必要子集，具体边界见 [storage-subset.md](storage-subset.md)。
  - 旧数据均为测试数据，不迁移；仅处理数据库文件，不清工作区。
