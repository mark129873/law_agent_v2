# PRODUCT.md -- 产品描述

本文件只描述**用户可见的产品行为与需求**（界面、交互、展示规则、边界）。

## 1. 产品定位

单用户本地 Web 版个人助手 harness。用户在浏览器里与一个具备工具执行能力的 AI 助手对话，助手可以读写文件、执行命令、管理任务板、派出子助手完成子任务；全部对话流式呈现，工作过程折叠收纳，会话可持久保存并随时继续。

- 布局：左侧会话列表 + 中间对话流 + 右侧 subtask 查看面板（点击 subtask 卡片时出现）。
- 界面语言：中文。主题：浅色单主题（风格参照 codex/ZCode 桌面端的冷静极简）。仅桌面，不做窄屏适配。
- 无登录、无多用户，仅监听本机 127.0.0.1。

## 2. 会话管理

1. **新建会话**：侧栏"新建"按钮；会话在发出首条消息时才真正入库（draft 语义）。标题取首条用户消息前 30 字符，不可重命名。
2. **会话列表**：按更新时间倒序；每项显示标题、最近更新时间、累计 token 数；生成中的会话显示呼吸状态点（切走后仍可见后台进度）。
3. **删除会话**：删除按钮→确认弹窗→**永久删除**（无归档概念）；数据库层面为软删除标记。运行中的会话不可删除（先停止）。
4. **继续会话（resume）**：点击列表项打开旧会话，回看全部历史消息并继续对话；上下文从存储重建。
5. **空状态**：无会话或未选会话时，中央显示欢迎语与"新建会话"引导。
6. **地址与刷新恢复**：选中会话（含尚未发首条消息的草稿）后地址为 `/session/{会话id}`；刷新或重开浏览器后按地址恢复该会话的完整回放。草稿（无落盘内容）与未知/已删除的会话地址刷新后回首页。

## 3. 对话与工作块（ZCode 桌面端同款形态）

### 3.1 输入
- 多行输入框：Enter 发送，Shift+Enter 换行。
- 同一会话同时只允许一个进行中的回复；重复发送提示"该会话正在生成中"。不同会话之间可并行生成。

### 3.2 工作块（turn 的过程展示）
每个回复轮次（turn）渲染为：**用户消息 → 工作块（可折叠）→ 最终回复（块外完整渲染）**。

工作块头部状态机（ZCode 桌面端同款）：
| 状态 | 块头文案 | 行为 |
|---|---|---|
| 生成中 | 工作中 {耗时}（每秒跳动） | 默认展开 |
| 已完成 | 已工作 {耗时} | 完成瞬间自动收起，点击展开回看 |
| 已停止/已中断 | 已停止 {耗时} | 强制展开（用户点了停止，或服务中断） |

- 耗时格式（codex 阶梯）：<60s 显示 `45s`；<1h 显示 `3m 05s`；≥1h 显示 `1h 00m 00s`。
- 耗时口径：等待用户审批的时间不计入（服务端记账的"有效工时"）。历史轮的耗时是落盘的固定事实，不随后续时间增长。

### 3.3 块内条目
- **工具调用卡片**：显示工具名、参数摘要、状态词（等待中/执行中/已执行/执行失败/已拒绝/已停止）；输出默认折叠预览，可展开看全文。连续的只读类工具 ≥2 个聚合为"探索"组，连续的命令类工具 ≥2 个聚合为"执行"组。
- **subtask 卡片**：显示子助手目标与状态；点击后右侧面板显示该子助手的实时输出；历史 subtask 保留，可随时点开回看。
- **任务板卡片**：todo 任务板的实时状态（[ ] 待办 / [>] 进行中 / [x] 已完成），随更新覆盖刷新。
- **审批卡片（留痕）**：每次审批请求与用户决定（批准/拒绝）在块内留痕。
- **错误卡片**：API 失败等错误以红色内联卡片展示。
- **已压缩提示**：上下文压缩发生后，块内出现"已压缩"提示条。

### 3.4 最终回复
块外完整 Markdown 渲染（代码高亮），悬停显示复制按钮。停止生成后，已流式输出的部分保留为带"已停止"标记的消息，不丢弃。

### 3.5 消息操作
- 复制：任意消息悬停出现复制按钮。
- 重试：错误卡片提供"重试"，重发上一条用户消息（回滚本轮重跑）。
- 重新生成：assistant 回复悬停出现"重新生成"，保留用户消息、回滚其后内容仅重跑该轮。

## 4. 交互审批

- 助手执行高危操作前（shell 删除类命令、chmod、管道执行、越界写文件等），界面弹出审批框：工具名、参数、风险原因。
- 用户选择"批准"或"拒绝"；等待期间可点"停止"终止本轮。
- 拒绝后，拒绝理由作为工具结果返回给模型，模型自行改道继续本轮。
- 每次审批请求与决定在会话流中留痕（见 3.3）。

## 5. 上下文占用

- 会话头部显示当前 token 用量 / 上下文窗口的进度。
- 发生上下文压缩时，工作块内出现"已压缩"提示条。

## 6. 边界行为

| 场景 | 行为 |
|---|---|
| 刷新页面时审批未决 | 从会话回放恢复审批弹窗，仍可响应 |
| 系统提示词被修改 | 只对其后的回复轮次生效，历史轮不受影响 |
| 多标签页打开同一会话 | 仅发起回复的标签页接收实时流，其余标签页刷新后回看 |
| 服务重启/崩溃时正在生成 | 该轮标记"已停止"，保留已生成部分，可重新生成 |
| 刷新页面时正在生成 | 已生成部分从存储回放显示（不做断点续流） |

## 7. 明确非目标（v1 不做）

图片/文件附件、会话搜索、标题重命名、深色主题与主题切换、多语言、移动端适配、SSE 断点续传、登录鉴权与多用户、跨会话记忆、每会话模型切换、workspace 文件浏览器、会话导出、推理(thinking)内容展示（模型侧已全局关闭思考）、会话归档（删除即永久删除）、长会话游标分页与虚拟化（v1 全量返回，留 v2）。
